# MySQL Practice Questions – SELECT & SEARCH

## About This Project
This repository contains 20 MySQL practice questions and their solutions. The project is designed to improve SQL query-writing skills and understand database operations.

## Database Information
- Database Name: customers_database
- Table Name: customers
- Total Records: 50

## SQL Concepts Covered
1. SELECT
2. WHERE
3. AND / OR
4. BETWEEN
5. LIKE
6. DISTINCT
7. COUNT
8. MAX
9. Subqueries
10. IS NULL
11. REGEXP
12. LENGTH
13. ORDER BY
14. LIMIT
15. IN

## Practice Questions
This project includes 20 SQL queries covering:
- Customer filtering
- Income-based filtering
- Pattern matching
- Highest and second-highest income
- Handling NULL values
- Finding unique states and cities
- Date-based filtering
- Sorting and limiting records

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Create the customers_database database.
3. Execute the database creation and INSERT statements.
4. Open MySQL_Select_Search_Questions.sql.
5. Execute the queries individually or together.
